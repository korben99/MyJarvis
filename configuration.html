Configuration Jarvis

Sélectionner le fichier .env

Glissez-le sur cette zone, ou utilisez le sélecteur. Pour des raisons de sécurité, un document ouvert localement ne peut pas accéder au disque de lui-même.

Le fichier n'apparaît pas dans la liste ? macOS masque par défaut les fichiers dont le nom commence par un point.
⌘⇧. affiche les fichiers masqués  ·  ⌘⇧G permet de saisir directement /opt/jarvis/.env

Champs sensibles — un champ laissé vide conserve sa valeur actuelle ; seule une saisie explicite la remplace.
Prise en compte — la configuration est lue au démarrage uniquement. Un jarvis-restart est nécessaire, suivi d'environ deux minutes de chargement du modèle.
Commandes d'installation (Google, modèles, diagnostic)

Un document ouvert dans un navigateur ne peut pas exécuter de commande sur la machine : c'est une restriction du navigateur, sans contournement. Les commandes ci-dessous sont à exécuter dans un terminal ; les boutons les copient dans le presse-papier.

Connecter un compte Google (Gmail + Agenda)

cd /opt/jarvis
./venv/bin/python scripts/generate_google_token.py --user ALICE1

Le script affiche un GOOGLE_REFRESH_TOKEN_<CODE>, à reporter dans le champ correspondant. Procédure complète : DOCS/GOOGLE.md.

Télécharger les modèles locaux

cd /opt/jarvis
./venv/bin/python scripts/download_models.py

Vérifier l'état des services après redémarrage

cd /opt/jarvis
./scripts/jarvis-status.sh

Exécution directe depuis la page

Trois approches sont envisageables, par complexité croissante. Un service local lié à 127.0.0.1 et démarré à la demande : quelques dizaines de lignes, au prix d'un processus supplémentaire à gérer. Un gestionnaire de schéma d'URL (jarvis://) enregistré par un bundle .app : un clic suffit, mais le bundle doit être signé et maintenu. Un raccourci Shortcuts invoqué via shortcuts://run-shortcut?name=… : l'approche la plus légère, le raccourci restant à créer manuellement. Aucune ne se justifie pour trois commandes exécutées une seule fois à l'installation.
